# Earnor

A high-fidelity landing page for Earnor, inspired by the Cawar landing page design.

## Tagline
Incentivizing crowdsourcing data annotation through financial literacy programs.

## Stack
- React
- Custom CSS (no Tailwind)

## Structure
- Modular React components in `src/components`
- Custom CSS in `src/styles`

## Getting Started
1. Install dependencies:
	```bash
	npm install
	```
2. Start the development server:
	```bash
	npm start
	```

---

This project recreates the look and feel of the provided Cawar landing page screenshot, adapted for Earnor.
